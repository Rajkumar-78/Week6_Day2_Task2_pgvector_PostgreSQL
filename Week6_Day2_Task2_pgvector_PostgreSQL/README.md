# Task 2 — pgvector in PostgreSQL

## Start database
Open Docker Desktop, then PowerShell:
```powershell
docker run -d --name pgvector-db -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=vectordb -p 5432:5432 pgvector/pgvector:pg16
```
If container already exists, run `docker start pgvector-db`.

## Install and run (PowerShell in this extracted folder)
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python task2_pgvector.py
```
Uses `all-MiniLM-L6-v2` (384 dimensions), inserts 20 embedded sentences, executes parameterized nearest-3 query using `<=>`, category-filtered query, and prints EXPLAIN ANALYZE before/after HNSW.

## Important plan note
With only 20 rows PostgreSQL normally chooses a sequential scan even after HNSW creation. For the after-index screenshot the script sets `enable_seqscan=off` temporarily to demonstrate the HNSW plan; it resets the setting immediately. This is only for demonstration, not a production setting.
